.. _v3.1.0:

3.1.0
=====

Enhancements
------------

* Added :attr:`~pynetdicom._config.VALIDATE_QUERY_IDENTIFIERS` to warn when
  a C-FIND, C-GET or C-MOVE query sent using a hierarchical Query/Retrieve
  information model has an *Identifier* with a missing or invalid
  *Query/Retrieve Level* (:issue:`568`)

Fixes
-----

* Fixed the default logging handlers for N-ACTION treating *Action Type ID* as mandatory (:issue:`1027`)
* Fixed being unable to resolve IPv4 address when using the hostname (:issue:`1033`, :pr:`1034`)
